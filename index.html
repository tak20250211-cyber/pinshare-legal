PinShare プライバシーポリシー

制定日：2026年7月26日

本プライバシーポリシーは、iOSアプリ「PinShare」（以下「本アプリ」）における利用者の情報の取り扱いを定めるものです。

1. 収集する情報

  • アカウント情報：メールアドレス、パスワード（暗号化して保存され、運営者は閲覧できません）
  • プロフィール情報：表示名、アイコン画像、自己紹介文（利用者が任意で設定したもの）
  • 投稿コンテンツ：利用者が投稿した写真・動画・テキスト、および投稿に利用者が付与した位置情報（スポットの場所）
  • 端末の位置情報：地図に現在地を表示し、投稿しやすくするために利用します。端末の現在地が他の利用者に共有されることはありません（共有されるのは、利用者が投稿時に自ら指定したスポットの位置のみです）
  • 利用状況に関する情報：本アプリはGoogle Firebaseを利用しており、サービスの提供・不正利用防止のために端末識別子や利用ログが自動的に記録されることがあります

2. 利用目的

  • 本アプリの機能（地図への投稿・閲覧、フォロー、メッセージ等）の提供のため
  • 不正利用の防止、通報への対応、利用規約違反の調査のため
  • サービスの改善・不具合の調査のため

3. 第三者への提供

法令に基づく場合を除き、利用者の個人情報を第三者に販売・提供することはありません。ただし、本アプリはデータの保存・認証基盤としてGoogle LLCが提供するFirebase（Authentication / Cloud Firestore / Cloud Storage）を利用しており、データは同社のサーバー（主に米国）に保存されます。Googleのプライバシーポリシーはこちらをご覧ください。

4. 写真・カメラ・位置情報へのアクセス

  • 写真ライブラリ：投稿する写真・動画の選択、および加工した写真・動画の保存のためにアクセスします
  • 位置情報：地図の現在地表示のために利用します。許可しなくても地図以外の機能は利用できます

5. ユーザー生成コンテンツについて

本アプリには利用者が投稿するコンテンツが表示されます。不適切なコンテンツを見つけた場合は、アプリ内の通報機能からご報告ください。運営者は通報を確認し、必要に応じてコンテンツの削除や利用者のブロック等の措置を行います。また、利用者は不快な相手をブロックすることができます。

6. データの保持と削除

  • 投稿は利用者自身がアプリ内でいつでも削除できます
  • アカウントと関連データの削除を希望する場合は、下記の連絡先までご連絡ください。確認のうえ速やかに削除します

7. 未成年の利用

本アプリの対象年齢はApp Storeの年齢制限指定に従います。保護者の方は、お子様の利用状況にご注意ください。

8. ポリシーの変更

本ポリシーは必要に応じて改定されることがあります。重要な変更がある場合は、アプリ内またはこのページでお知らせします。
